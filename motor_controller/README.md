# STM32F1 电机升降控制示例

这是一个基于 `STM32CubeF1` HAL 的示例，目标为 `STM32F103C8T6`
（Blue Pill，64 KiB Flash/20 KiB RAM）和 **HC-160A S2** 双路 H 桥模块。
程序同时驱动两路电机，并用 TIM3 的 1 kHz 中断实现毫秒级定时控制。

**全程不使用 PWM**：两个速度输入脚只当静态电平用，在 `GPIO_Init()` 里各写一次，之后永不再动：

* 通道 1 速度脚（PWM1）固定高电平 → 全速
* 通道 2 速度脚（PWM2）固定高电平 → 全速

上电后自动往复运行：

* 两个电机**同步**先正转 5 秒，再反转 5 秒，持续循环。
* 到达限位开关会立即刹车对应电机；自动周期仍会继续，到反方向时可恢复运行。
* 按住 `UP` 按钮，两路同时正转；按住 `DOWN` 按钮，两路同时反转；按键会退出自动模式。
* 发送 `r` 可重新进入 5 秒自动反转；发送 `s` 或 `X0` 停止自动模式。
* USART1（115200 8N1）支持 `A+5000`、`B-3000`、`X+10000` 等定时命令，单位为毫秒。

### HC-160A S2 控制逻辑

`A`/`B` 是通道 1 的两个方向输入，`a`/`b` 是通道 2 的；每路各有一个 PWM 脚作为速度输入。

| A | B | 通道 1 输出 |
| --- | --- | --- |
| 1 | 0 | 正转 |
| 0 | 1 | 反转 |
| 0 | 0 | **刹车**（绕组被低边管短接） |
| 1 | 1 | **未定义，固件绝不会产生这个状态** |

固件用一次 `GPIOB->BSRR` 写入同时改两个方向脚，所以换向过程中不会出现 `A=B=1` 的中间态。

> **`s`、`X0`、`A0` 命令是"刹车"，不是"断电"。** 因为速度脚恒高，桥臂一直带电，
> 被负载反拖时会发热。刹车不能替代机械限位。

## 默认接线

接线分两部分：**接到驱动板的只有 7 根**，其余是 STM32 自己的外设，与驱动板无关。

### A. 接 HC-160A S2 控制排针

| STM32F103C8 | HC-160A S2 | 说明 |
| --- | --- | --- |
| PA8 | PWM1（通道 1 速度） | 固定高电平，全速 |
| PA11 | PWM2（通道 2 速度） | 固定高电平，全速 |
| PB8 | `A`（通道 1 方向） | 每 5 秒翻转 |
| PB9 | `B`（通道 1 方向） | 每 5 秒翻转 |
| PB6 | `a`（通道 2 方向） | 每 5 秒翻转 |
| PB7 | `b`（通道 2 方向） | 每 5 秒翻转 |
| GND | 控制排针 `-` | 必须共地 |

如果只有一路电机，把 `CHANNEL_B_ENABLED` 改成 `0` 重新编译即可。

### B. STM32 自己的外设（都不接驱动板）

这四个脚在驱动板上没有对应端子，直接接在 STM32 上。全部用内部上拉，
所以每个开关只要两根线（信号 + GND），不需要外部电阻。

| STM32F103C8 | 接到 | 说明 |
| --- | --- | --- |
| PB10 | 下限位开关 | 装在行程下端，另一端接 GND，触发时拉低 |
| PB11 | 上限位开关 | 装在行程上端，另一端接 GND，触发时拉低 |
| PB12 | UP 按钮 | 另一端接 GND，按下拉低 |
| PB13 | DOWN 按钮 | 另一端接 GND，按下拉低 |
| PA9/PA10 | USB-TTL 的 RX/TX | 仅用于串口控制/状态 |

**这四样全都不接也能跑**：内部上拉使它们恒为"未触发/未按下"，5 秒自动反转
照常工作，只是没有行程保护、没有手动按钮、看不到串口。**不接限位就没有行程
保护**，机构撞到死点时电机会堵转到 5 秒时间到才反转，期间发热并可能拉跌供电。

### 为什么这六个信号脚都在带 FT 的位置

STM32F103 上 **PA0–PA7、PB0、PB1、PC13–PC15 不带 FT 标记**，不是 5V 容忍，
输入绝对最大额定是 `VDD+0.3V ≈ 3.6V`；PB2 以上、PB6–PB15、PA8–PA15 都是 FT。

从上电复位到 `GPIO_Init()` 跑完约有 **2–3 ms**，这期间所有 GPIO 都是**浮空输入**。
如果 HC-160A S2 的控制输入自带 5V 上拉，这些脚就会被拉到 5V、超出额定。
本固件把六个信号脚全部放在 FT 脚上，整条控制接口在复位窗口期都不怕 5V。

### 上电前用万用表确认

1. 记下控制排针的丝印原文，确认 `+`、`-` 的位置，以及两个 PWM 脚分别属于哪一路。
2. **断电**，通断档：控制 `-` 应与功率侧 `GND(-)` 相通；`GND(-)` 应与大电解电容负极相通
   （这是不靠丝印确认功率极性的唯一办法）。若不通，需要单独拉一根参考地线。
3. **只给功率侧上电**（限流 12V / 0.3A，不接电机，控制排针不接）：
   * 测 `+` 对 `-`：约 5V → `+` 是输出，悬空即可（不要和 Blue Pill 的 5V 并接，会和 USB/J-Link 打架）；
     0V → `+` 是输入，必须喂 5V，否则驱动逻辑不工作。
   * 测各控制输入脚对 `-`：**>3.6V 说明模块自带 5V 上拉**，这正是上面要挪到 FT 脚的原因。
4. **绝不从 `+9V-30V` 给 STM32 供电** —— Blue Pill 板载是 5V→3.3V LDO，9V 灌进去直接烧。
5. 电机大电流回路直接走功率侧 `GND(-)`，不要过控制排针的细线。

电机两根线接功率侧对应通道的端子（`A`/`B` 或 `a`/`b`）。电机必须使用驱动模块要求的
独立电源（`+9V-30V`），不能由 STM32 供电。先断开电机确认方向和限位逻辑，再接空载电机，
最后才接机械负载。如果某个电机转向相反，交换该电机的两根线即可（双推杆镜像安装时常见）。
如果限位开关是高电平有效，修改 `limit_active()`。

## 编译期开关

| 宏 | 默认 | 作用 |
| --- | --- | --- |
| `CHANNEL_B_ENABLED` | `1` | 置 `0` 可临时停用通道 2（PWM2 拉低，`a`/`b` 停在刹车），用于单电机调试 |
| `REVERSE_DEAD_TIME_MS` | `0U` | 换向前先刹车多少毫秒；`0` = 直接反向 |
| `AUTO_START_DIRECTION` | `1` | `1` = 上电先正转，`-1` = 先反转 |

**关于 `REVERSE_DEAD_TIME_MS`**：瞬间反转时电源电压与电机反电动势叠加，电流峰值约 **2 倍堵转**；
先刹车一段时间可把它降到约 **1 倍堵转**并让其衰减。但死区**不能消除**冲击——刹车阶段本身
电流就是 `反电动势/内阻`，同样是 1 倍堵转。设置后周期变成 `5000 + REVERSE_DEAD_TIME_MS`。

固件启动时会通过串口打印复位原因。若换向瞬间反复出现 `RESET: POR/BROWNOUT`，说明供电被拉跌，
把 `REVERSE_DEAD_TIME_MS` 改成 `200U`。（STM32F103 **没有**掉电复位 BOR 标志位，那是 F2/F4
才有的；F103 上供电跌落表现为 `PORRSTF`。）

## 编译和烧录

需要安装包含 newlib 的 GNU Arm Embedded Toolchain、`make`，以及 SEGGER J-Link 软件。
本工程也保留 ST-LINK/OpenOCD 目标。注意：Homebrew 的 `arm-none-eabi-gcc` 公式是
不带 C 运行库的 compiler-only 包，不能用于本工程；请安装官方 ARM GNU Toolchain `.pkg`：

```sh
# 如果使用 Homebrew，下面这个 cask 会打开需要管理员密码的 .pkg 安装器
brew install --cask gcc-arm-embedded
```

也可以从 ARM 官网下载并双击 `.pkg` 手动安装。安装后确认：

```sh
export ARM_GNU_TOOLCHAIN=/Applications/ArmGNUToolchain/15.3.rel1/arm-none-eabi
export PATH="$ARM_GNU_TOOLCHAIN/bin:$PATH"
arm-none-eabi-gcc --version
arm-none-eabi-gcc -print-file-name=libc.a   # 必须输出一个完整路径，不能只输出 libc.a
```

然后在仓库根目录运行：

```sh
make -C motor_controller
make -C motor_controller flash PROGRAMMER=jlink
```

J-Link 的 SWD 接线如下（开发板底部 4 针排针）：

| J-Link | STM32F103C8T6 | 说明 |
| --- | --- | --- |
| SWDIO | PA13 / SWDIO | 数据 |
| SWCLK | PA14 / SWCLK | 时钟 |
| GND | GND | 共地 |
| VTref/3.3V | 3.3V | 电平参考；按 J-Link 型号决定是否给板供电 |
| nRESET | NRST | 建议连接 |

请安装 [SEGGER J-Link Software and Documentation](https://www.segger.com/downloads/jlink/)，
确保 `JLinkExe` 在 PATH 中。烧录命令会自动擦写、校验、复位并运行：

```sh
make -C motor_controller flash PROGRAMMER=jlink
```

如果提示 `JLinkExe: command not found`，可直接使用 SEGGER 安装目录中的 `JLinkExe`，或将其
所在目录加入 PATH。J-Link 的 `VTref` 只用于检测目标电压；不要把 5 V 接到 STM32 的 3.3 V 引脚。

如果不想修改 PATH，也可以直接指定工具链目录：

```sh
make -C motor_controller TOOLCHAIN=/Applications/ArmGNUToolchain/15.3.rel1/arm-none-eabi
```

## 串口定时命令

命令以回车或换行结束，时间单位是毫秒；不写时间表示持续运行，直到发送停止命令。

| 命令 | 作用 |
| --- | --- |
| `A+5000` | A 路上升 5 秒 |
| `A-3000` | A 路下降 3 秒 |
| `B+5000` / `B-3000` | B 路定时升/降 |
| `X+10000` / `X-10000` | A、B 两路同时定时升/降 |
| `A0` / `B0` / `X0` | 刹车对应路（**不是断电**，桥臂仍带电） |
| `u` / `d` / `s` | 两路持续正转/反转/刹车，并退出自动模式 |
| `r` | 重新进入自动模式：正/反各 5 秒循环 |

例如，发送 `X+8000` 后，两路会按当前方向运行约 8 秒；到达上/下限位时会提前刹车。

若你的芯片不是 STM32F103C8（例如 F103RB、F103CB），请同步修改 Makefile 中的
`MCU`、链接脚本的 Flash/RAM 大小以及启动文件。PA8/PB6–PB9 等引脚也应按实际原理图修改。

## 安全说明

这是开环控制示例，没有位置反馈和过流保护。限位开关、急停和机械保护应当独立于软件设计；
首次通电时建议抬起电机或串入限流电源。

两个速度脚都固定高电平，意味着**没有软件调速，也没有软件断电**：上电即两路全速运行，
串口 `s` 只是刹车。调试时建议先拔掉电机线。

**换向冲击**：默认无死区，且两个电机同时换向，冲击电流约为单路堵转的 2 倍再翻倍。
建议限流电源先设 1–2A 试、功率侧并大容量电解电容、串保险丝。
若串口反复打印 `RESET: POR/BROWNOUT`，说明供电确实被拉跌，把 `REVERSE_DEAD_TIME_MS` 改成 `200U`。

**100% 直流占空比**：部分大电流 H 桥用自举电容给高边栅极供电，靠开关动作刷新；
若该板是这种结构，长时间恒高会让高边栅极电压跌落、MOSFET 进入线性区发热。
厂家标称"高电平 = 全速"暗示用的是电荷泵，但那是厂家说法不是实测。
**验收方法**：接电机在 100% 直流下跑 10 分钟，摸 MOSFET 和栅极驱动芯片的温度，只是温热就没事。

不要在无人看守时让 `u`/`d` 命令长期保持。
